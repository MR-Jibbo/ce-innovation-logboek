
CE-Innovation Logboek
Installatiehandleiding voor Mac en Windows
Downloaden
Ga naar: github.com/MR-Jibbo/ce-innovation-logboek/releases
Download het bestand dat bij jouw systeem hoort:
Mac met Apple Silicon (M1/M2/M3/M4, check via Apple-menu, Over deze Mac): CE-Innovation Logboek-x.x.x-arm64.dmg
Mac met Intel-chip (ouder dan eind 2020): CE-Innovation Logboek-x.x.x.dmg
Windows: CE-Innovation Logboek Setup x.x.x.exe
Installeren op Mac
1. Open de .dmg en sleep het app-icoon naar de Programma's-map (Applications).
2. Open Terminal via Spotlight: druk op cmd+spatie, typ Terminal en druk op Enter.
3. Typ of plak deze regel in Terminal en druk op Enter:
xattr -cr "/Applications/CE-Innovation Logboek.app"
Dit hoeft maar één keer, meteen na de installatie. Zonder deze stap toont macOS zo meteen een verwarrende melding dat de app
beschadigd zou zijn. Dat is niet zo, macOS toont dit standaard bij apps zonder betaald Apple-ontwikkelaarscertificaat, en deze ene regel
voorkomt die melding.
4. Open de app vanuit Launchpad of Programma's.
Installeren op Windows
1. Open de .exe door erop te dubbelklikken.
2. Zie je Windows heeft je pc beschermd? Klik op Meer info, daarna op Toch uitvoeren. Dit is normaal voor apps zonder
betaald certificaat, en hoeft maar één keer.
3. Volg de installatiewizard en open de app daarna vanuit het Startmenu.
Waar wordt mijn data opgeslagen?
Bij de eerste keer openen vraagt de app om een map te kiezen op je computer (bijvoorbeeld in Documenten). Al je projecten en
bewijsstukken worden daar lokaal opgeslagen. Je kunt deze map later altijd wijzigen via Instellingen, Opslaglocatie.
